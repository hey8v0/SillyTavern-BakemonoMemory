# 剧情剪辑台模块化约定

## 目标

在不改变聊天记忆、配置结构、注入结果和界面行为的前提下，把 `index.js` 按职责逐批拆分。模块化批次必须保持可单独回退，不做一次性重写。

## 依赖方向

```text
index.js（启动与装配）
  -> ui（读取表单、渲染、事件）
  -> features（摘要、表格、向量、收纳）
  -> core（酒馆适配、状态、迁移、保存）
  -> shared（纯函数）
```

- `shared` 不得读取 DOM、酒馆上下文、聊天状态或本地存储。
- 向量数学、文本解析等纯模块不得弹 toast、保存数据或触发渲染。
- 功能模块不得反向导入 `index.js`。
- UI 只发出操作意图，不在渲染函数中悄悄保存表单。
- 数据结构迁移只能由未来的 `core/migrations.js` 负责。

## 兼容性红线

- 不改 `bakemonoMemory` 存储键。
- 不改变现有 `chat_metadata` 与全局配置字段的含义。
- 不让模块抽取顺便触发数据迁移。
- 不把运行时派生数据改成不可枚举字段或 WeakSet 快捷缓存。
- 不恢复工作台关闭时的隐藏页面全量渲染。
- 不在重要操作开始前整页重绘尚未保存的表单。
