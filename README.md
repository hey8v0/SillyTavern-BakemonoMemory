# 剧情剪辑台 / Bakemono Memory

SillyTavern 第三方扩展。它把长篇 RP 里的正文摘要、阶段总结、多次总结、表格记忆和向量召回整理成一套长期记忆工作台，目标是让几百楼、几千楼甚至更长的聊天还能保持剧情连续。

插件入口默认在左下角魔法棒菜单里，也可以在扩展设置中开启顶部导航栏入口。

## 适合谁用

- 你已经让角色在正文后输出 `<bakemono>` 摘要，并用酒馆正则在旧楼层只保留摘要。
- 你没有提前做摘要，但想把旧聊天分批补课成可注入的长期记忆。
- 你想把角色关系、物品、世界设定、剧情指导等内容整理成表格。
- 你想用 embedding / rerank / 查询重写，从旧剧情中按需召回原文或摘要。
- 你主要在手机端使用 SillyTavern，但也希望 PC 端能看懂、能维护。

## 核心功能

### 摘要与总结

- 扫描当前聊天中的摘要块或正文片段。
- 支持已有摘要模式、通用旧正文补课、补写缺失摘要。
- 支持手动或自动生成阶段总结。
- 支持把多个阶段总结继续压缩成“多次总结 / 长期总览”。
- 阶段总结和多次总结支持单次生成或批量生成。
- 已保存摘要可以编辑标题和正文；危险删除需要确认。
- 摘要树 / 时间线用于查看“普通摘要 → 阶段总结 → 多次总结”的覆盖关系。

### 批量摘要

- `旧正文补课`：把没有摘要的旧聊天分批压缩进插件记忆，不改原正文。
- `补写缺失摘要`：检查缺少摘要的助手楼层，生成 `<bakemono><details><summary>剧情摘要</summary>...</details></bakemono>` 并追加回原楼层正文。
- 支持楼层范围、包含隐藏楼层、批量大小、任务队列和卡住任务清理。

### 注入策略

- 已有摘要模式：普通摘要通常随正文正则走，不重复注入；阶段总结和多次总结进入长期记忆。
- 通用补课模式：普通补课摘要可以临时注入；被阶段总结覆盖后自动退出普通注入。
- 注入顺序大致为：多次总结 → 阶段总结 → 按策略决定的普通摘要 → 表格记忆 → 向量召回。
- 使用 `setExtensionPrompt(...)` 注入，不直接把总结刷进聊天正文。

### 表格记忆

- 支持多张自定义表格。
- 表格框架可以按全局、角色、当前聊天保存。
- 支持只读表、可写表、AI 是否允许修改。
- 支持随正文输出 `<tableEdit>` 后自动解析表格修改。
- 支持表格内容注入上下文，并提供总开关避免重复注入。

表格修改格式示例：

```text
<tableEdit>
insertRow(0, {"0":"角色名", "1":"关系", "2":"备注"})
updateRow(0, 1, {"2":"新的备注"})
deleteRow(0, 2)
</tableEdit>
```

### 向量记忆

- 支持本地 fallback 向量和 OpenAI-compatible embedding API。
- 支持查询重写、embedding 初召回、轻量 rerank、全文/摘要分档注入。
- 可以选择是否索引隐藏楼层、是否索引用户楼层、是否跳过最近可见窗口。
- 正文索引和摘要索引分开，避免召回全文时重复带上摘要块。
- “上次召回详情”展示查询重写、候选、分档和最终注入内容，方便调参。

### 楼层收纳

- 支持像隐藏助手一样自动只保留最近 N 楼正文。
- 支持手动输入楼层范围隐藏 / 恢复。
- 支持恢复由插件自动收纳隐藏的楼层。
- 控制台会尽量显示酒馆实际隐藏楼层数量。

## 安装

把插件文件夹放入 SillyTavern 第三方扩展目录：

```text
SillyTavern/public/scripts/extensions/third-party/SillyTavern-BakemonoMemory
```

然后刷新 SillyTavern，在扩展 / 魔法棒菜单中打开“剧情剪辑台”。

如果你从 GitHub 下载 zip，请确保解压后的目录中直接包含这些文件：

```text
manifest.json
index.js
settings.html
style.css
README.md
```

不要让文件多包一层无关目录。

## 推荐工作流

### 已有摘要模式

1. 让角色回复正文后输出 `<bakemono>` 摘要。
2. 使用酒馆正则让旧楼层只保留摘要，节省 token。
3. 在剧情剪辑台中扫描摘要。
4. 摘要积累到一定数量后生成阶段总结。
5. 阶段总结确认后隐藏已覆盖楼层。
6. 阶段总结继续积累后生成多次总结。
7. 开启向量记忆，用于召回旧细节。

### 没有摘要的旧聊天

1. 打开批量摘要。
2. 选择“旧正文补课”。
3. 设置楼层范围和每批楼数。
4. 生成并确认补课摘要。
5. 生成阶段总结，让旧正文长期记忆进入上下文。
6. 后续继续 RP 时，可以切回已有摘要模式或继续使用自动正文摘要。

### 某些楼漏了摘要

1. 打开批量摘要。
2. 选择“补写缺失摘要”。
3. 指定范围或留空全选。
4. 生成草稿后确认应用。
5. 插件会把摘要追加到对应助手楼层末尾，再重新扫描。

## 开发与维护

主要文件：

- `manifest.json`：扩展清单和版本号。
- `index.js`：核心逻辑。
- `settings.html`：工作台界面结构。
- `style.css`：界面样式。
- `DEVELOPMENT_HANDOFF.md`：详细开发交接文档、历史脉络和注意事项。

本地检查：

```powershell
node --check BakemonoMemory\index.js
git -C BakemonoMemory diff --check
```

查看提交历史：

```powershell
git -C BakemonoMemory log --oneline -20
```

如果要在新的 Codex 窗口继续开发，请先读取：

```text
BakemonoMemory\DEVELOPMENT_HANDOFF.md
```

这个文件比 README 更细，记录了当前结构、用户偏好、踩过的坑和每次提交的大致更新内容。

## 注意事项

- 插件仍在快速迭代中，升级前建议备份重要聊天。
- 大批量补写摘要、表格自动解析、向量建索引都可能消耗额外 API 额度。
- 手机端 WebView 对滚动和动画很敏感，如果遇到滑不动或闪屏，优先减少展开面板并刷新页面。
- 不建议一次性对几百楼做无确认的危险操作；插件会尽量在删除、清空、隐藏等操作前弹出确认。
