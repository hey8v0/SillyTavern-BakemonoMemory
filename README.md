# Bakemono Memory 剧情剪辑台

SillyTavern 第三方扩展，用来扫描聊天里的摘要或正文片段，生成剧情摘要、阶段总结、史诗简史，并把长期记忆注入后续回复上下文。

## 功能

- 魔法棒菜单入口，无悬浮球。
- 通用扫描规则：可配置读取标签、排除标签、全文管线。
- 两套初始工作流预设：`默认 Bakemono 手账` 和 `通用正文压缩`。
- 手动/自动总结：自动总结只生成草稿，确认后才保存。
- 分批补课旧正文：批次、楼层范围、推荐标题由插件写入提示词，避免模型乱猜章节号。
- 草稿箱：支持编辑标题、编辑内容、重新总结、确认保存、丢弃。
- 保存排序：草稿确认后按来源楼层进入摘要树和长期记忆，不按点击保存顺序打乱时间线。
- 任务队列、摘要树/时间线、保存记录分页。
- 工作流预设：保存提示词、扫描规则、分类规则、美化分段和自动总结设置。
- 注入内容：通过 `setExtensionPrompt` 注入长期剧情记忆。

## 安装

把 `BakemonoMemory` 文件夹放入：

```text
SillyTavern/public/scripts/extensions/third-party/
```

然后刷新 SillyTavern，在左下角魔法棒菜单打开 `剧情剪辑台`。

## 文件

- `manifest.json`：扩展清单
- `index.js`：扩展逻辑
- `settings.html`：工作台界面
- `style.css`：界面样式
