# 剧情剪辑台 / Bakemono Memory

给 SillyTavern（酒馆）长篇角色扮演用的记忆扩展。聊得越久，模型越容易忘记前面发生过什么；剧情剪辑台帮你把剧情整理成摘要、阶段总结和长期总览，记录人物关系与世界状态，并在每轮对话时把真正需要的记忆交给模型。

当前版本：**v1.38.0** · [更新日志](CHANGELOG.md)

> 适合几百楼、几千楼的连续剧情，也能给以前没做过摘要的旧聊天补课。界面按手机优先设计，可以跟随酒馆主题，也可以选“场记板 · 夜”“白板 · 日”或自定义配色。

## 它能帮你做什么

- **整理剧情**：把一段段剧情摘要整理成“阶段总结”，再把多个阶段压缩成更长的“多次总结”，模型不必每轮重读全部旧聊天。
- **记住人物与世界**：“剧情事实”把人物、关系、地点、物品、线索和设定记成卡片，每攒够几条剧情摘要（默认 6 条）整理一次，聊天空闲时把剩下的也整理掉；还会写一段主线与伏笔的反思。卡片随时可以改，改过的字段不会被覆盖。
- **找回旧细节**：向量记忆会从很久以前的聊天里，找回和当前场景相关的原文或摘要。
- **先检查再保存**：生成的总结先进入“待确认”，你看过、改过再存进长期记忆；保存后也能撤回。
- **看得清楚**：首页显示整理到哪一楼、这一轮注入了什么、占了多少 Token；还能查看上一轮实际发给模型的完整提示词。
- **收纳旧楼层**：隐藏已经整理好的旧楼层，减轻长聊天的负担（只是隐藏，不会删除）。

## 安装与更新

### 用 Git 安装（推荐）

在酒馆的第三方扩展目录 `SillyTavern/public/scripts/extensions/third-party` 里执行：

```bash
git clone https://github.com/hey8v0/SillyTavern-BakemonoMemory.git
```

以后更新，在插件目录里执行：

```bash
git pull origin main
```

也可以在酒馆的“扩展管理”里直接更新。本插件没有开启自动更新，需要手动点一下。

### 下载 ZIP

在 GitHub 下载 ZIP，解压到上面的扩展目录。打开插件文件夹时，应该直接看到 `manifest.json`、`index.js` 等文件，而不是又套了一层文件夹。

### 打开插件

刷新或重启酒馆后，从左下角魔法棒菜单打开“剧情剪辑台”。也可以在扩展设置里打开“在顶部导航栏显示入口按钮”。

更新前建议先备份重要聊天。更新后如果还是旧界面，请强制刷新浏览器缓存。

## 第一次使用

1. 打开剧情剪辑台，首页会显示当前聊天的整理情况。
2. 进入 **设置中心 → 摘要方式**，回答一个问题：“新回复的摘要从哪里来？”
   - **回复里已经自带摘要**：你的角色卡或预设会让模型写摘要块。
   - **让模型在回复里顺带写摘要**：由插件在提示词里提出要求，不额外花钱。
   - **每次回复后另外生成摘要**：回复结束后单独调用一次模型，会增加用量。
   - **需要时再手动生成**：只有你点按钮时才生成。

   选好后点顶部的 **保存设置**。
3. 聊一段剧情，摘要积累起来后，到 **总结** 页点 **生成阶段总结**。
4. 到 **待确认** 检查生成结果，确认后保存。
5. 回到首页，看看已经整理到哪一楼、这一轮注入了哪些记忆。

不用一开始就弄懂所有设置。插件里的 **使用说明** 有更详细的分步教程。

## 按你的情况开始

### 回复里已经有摘要

适合角色卡或预设已经让模型在回复末尾写 `<bakemono>` 摘要块的聊天。

1. 摘要方式选“回复里已经自带摘要”。
2. 摘要积累到一段剧情后，在 **总结** 页生成阶段总结。
3. 确认保存后，可以到 **设置中心 → 楼层收纳** 隐藏已经整理好的旧楼层。
4. 阶段总结多了以后，切到“多次总结”再压缩一次。
5. 聊天很长时，可以开启向量记忆，找回被压缩掉的旧细节。

### 旧聊天以前没有摘要

适合已经聊了很多楼、之前没用过剧情剪辑台的存档。

1. 先在 **设置中心 → 摘要方式** 选好以后新回复的摘要方式。
2. 在同一页点 **去补写旧聊天**，插件会按你选的方式预先选好处理方式：
   - 摘要写在回复里时，选“补写缺失摘要”，把摘要补回原来的楼层。
   - 摘要存在插件里时，选“旧正文补课”，不改动原楼层。
3. 先填一小段楼层范围试试，确认结果满意再逐步扩大。不要一次处理几百楼。
4. 补完后，再把这些摘要整理成阶段总结。

### 只有少数楼漏了摘要

到 **总结 → 剧情摘要**（下面的补写旧聊天表单），选“补写缺失摘要”，填上楼层范围（留空则检查全部）。生成的结果会先进入待确认，确认后插件会把摘要追加到对应楼层末尾。这是少数会修改原聊天内容的功能。

## 各个页面

从左上角菜单进入：

| 页面 | 用途 |
| --- | --- |
| **剪辑台** | 首页：现在该做什么、每一楼整理到了哪一步、本轮注入了什么和占比、当前生效的设置 |
| **总结** | 生成阶段总结和多次总结，回看已有总结、摘要树，补写旧聊天 |

| **设置中心** | 摘要方式、扫描识别、注入内容、生成模型、提示词、楼层收纳、主题、整套配置、撤回 |
| **使用说明** | 快速开始、推荐流程、功能说明、常见问题和详细手册 |

## 主要功能

### 总结

剧情按三层整理：**剧情摘要**（短片段、细节多）→ **阶段总结**（一章的长期记忆）→ **多次总结**（跨越多个阶段的时间线）。已经被上一层覆盖的内容不会重复注入，以节省 Token。

在 **总结** 页点 **生成阶段总结**（或多次总结）后，在对话框里选“生成一条”或“分批生成”，再选择范围。生成结果都会先进入待确认。**摘要树** 可以看出哪些摘要已经被哪条总结覆盖。

### 剧情事实

稳定的东西记成卡片：人物（处境、目标、持有、性格、外貌、备注）、关系、地点、物品、线索（没了结的约定和伏笔）、设定、便签。它不是每一轮都记，而是每攒够几条剧情摘要整理一次（默认 6 条，可以改），聊天空闲 10 分钟后也会把剩下的整理掉：把这段剧情里变了的卡片整张重写，没变的不动，明确结束的标记为已结束。每次整理还会写一段反思：当前主线、未回收的伏笔、人物弧线。

- **默认开着**：每整理一次多一次请求。不想要就在页面顶部关掉，会记住；也可以把“每攒几条摘要整理一次”调大。
- **卡片可以改**：名字、别名和每个字段都能编辑，你改过的字段之后不会被整理覆盖。还能固定注入、标记结束、合并重复的卡、手动新建。便签只有你能写，模型只读，适合放写作要求。
- **先审再用**：打开后整理结果先进“待确认”，列出会新建、修改、结束哪些卡片，点“应用到卡片”才生效。
- **变化与撤回**：切到“变化”能看每一次整理改了什么，最近一次可以撤回；撤回只退这批整理改过的字段，你自己改过的保留，这批读过的摘要重新算作没整理。没有变化的整理也留一条记录。
- **哪些摘要算整理过**：按每条摘要记，不只看楼层号。给旧楼层补写的摘要、改过的摘要会重新整理，整理时会标明它们早于现状，不会把人物现状改回去；整理期间重 roll 或改了正文，这次结果作废、之后重来，不会卡住队列。积压很多时每批最多 20 条接着排，手动点一次会告诉你本次几条、还剩几条，想停就在队列里暂停。
- **变了、传闻、拿不准**：目标完成、物品丢失这类“不再成立”的信息，模型会把字段清空并在备注里留一句“曾经：…”，不会让旧目标一直注入。角色说的、猜的进备注并标【声称】【猜测】【某某认为】，被推翻的旧说法标【已推翻】，不会写进处境、持有者这些现状字段。材料和卡片对不上又分不清对错、或者两个称呼不确定是不是同一个人时，模型不改卡片，页面顶部出现“待裁决”，由你点“采用材料”或“保留现状”。同名的人物、地点、物品是三张卡，不会并成一张。
- **经过**：人物在哪、物品在谁手上、关系到哪一步、线索了没了，这些关键字段每次变化都记在卡片的“经过”里（每张最多 12 条，最旧的让位），注入时带上最近两次“曾经：…（到第几楼）”，模型知道现在是什么、以前是什么。死亡或了结的卡不再主动注入，但最近楼层点到名字时会带出来并标“已结束”。
- **伏笔与约定**：不再让模型每次重写一段文字，而是从“线索”卡里状态还没了结的派生；了结了就自动退出提醒，卡片还在，点名能找回。
- **和向量记忆配合**：最近对话点到某张卡（哪怕用的是别名），这张卡的所有称呼都会加进向量召回的关键词，旧摘要里用的是本名也找得到；召回回来的旧摘要点到的卡片，也会一起注入。不多发请求，没配 Embedding 时这部分不起作用。
- **空闲整理**：按最后一条消息的时间算。回到前台、刷新或重开聊天时如果已经够久，马上整理；页面被手机冻结或浏览器关着的时候不会整理。
- **注入**：每一轮只发最近几楼提到的卡片，加上固定注入的和未了结的线索；总量有自己的预算。
- **以前的剧情状态和表格**：1.33 起已经移除。老聊天里的数据还在，“剧情事实”页顶部可以一键导入成卡片；只补充，不覆盖。

### 向量记忆

从很久以前的聊天里找回和当前场景相关的内容。开启后，每次生成回复前会自动检索。

- 一楼一条：够像的楼带整段正文，其余带这一楼的摘要。“最多带几条摘要”“最多带几条正文”分开设，带上的内容不截断。
- 默认使用本地轻量检索，适合人名、地名这类明确的词；想要更好的语义检索，可以配置兼容 OpenAI 格式的 Embedding 接口。
- “上次召回”列出找到的每一条：哪些会注入、哪些这次不带和原因，点开能看分数和匹配到的词。
- 重点关键词可以自己填；用模型改写时，模型每轮还会从最近的对话里挑几个关键词一起加分，不多花请求。

### 注入内容

插件通过酒馆的扩展提示词把记忆交给模型，不会写进聊天正文。在 **设置中心 → 注入内容** 里可以设置是否注入、插入深度、消息角色和注入模板。首页“本轮注入”中的每个模块都可以点开，查看具体内容。

顶部右侧的小标签显示注入状态：“注入 N 字”表示已准备好的字数，“无可注入”表示已开启但暂时没有可用记忆，“注入已关”表示总开关关闭。

### 楼层收纳

自动只保留最近 N 楼可见，也可以手动隐藏或恢复指定楼层。收纳只是隐藏，不会删除。建议确认总结已经保存好之后再收纳。

### 生成模型与提示词

总结可以使用酒馆当前的主模型，也可以单独配置一个兼容 OpenAI 格式的接口。阶段总结、多次总结、补写摘要、旧聊天补课各有自己的提示词，可以编辑，也可以恢复默认。

### 外观与整套配置

默认跟随酒馆主题；酒馆主题是半透明的也没关系，插件背景始终不透明。也可以选择“场记板 · 夜”“白板 · 日”，或自己调配色并存成配置。**整套配置** 可以保存、导出和导入全部设置，方便备份或换设备。

## 设置怎么保存

- 设置页修改后，点顶部的 **保存设置** 才会生效。没保存就离开页面或关闭剪辑台时，插件会提醒你保存、放弃，还是留在本页。
- 设置对所有角色卡通用，换角色卡不用重新配置。
- 剧情记忆按聊天分开保存，A 角色卡的记忆不会注入到 B 角色卡。

## 会不会多花钱

**不调用模型的操作**：扫描、查看总结和提示词、搜索、手动编辑、隐藏或恢复楼层、撤回。

**可能产生额外请求的操作**：生成总结、补写旧聊天、“每次回复后另外生成摘要”、自动总结、整理事实（每个阶段总结一次）、外部 Embedding 建立索引、查询改写。

第一次使用自动功能时，建议先用一小段聊天确认效果和用量。

## 手机使用建议

- 几百楼以上的旧聊天，先用小范围、小批次处理。
- 不要同时开好几个大批量任务。
- 任务卡住时，先去 **待确认** 查看队列，不要反复点生成。
- 向量索引很大时，可以缩小索引范围和结果数量。
- 手机系统可能会冻结后台页面，这时插件无法继续联网；回到前台后会自动接着处理。

## 备份与安全

- 更新插件前、大批量处理前，先备份重要聊天。
- **维护 → 记忆备份与诊断** 可以导出当前聊天的摘要、草稿、剧情事实和账本（也带上老聊天里以前的表格和剧情状态），恢复前会先自动下载一份当前数据。备份文件包含私人剧情，请妥善保管，不要当作诊断报告公开。
- 脱敏诊断只包含版本、数量和状态，不含正文、角色名、接口地址或密钥，可以放心发给开发者。
- 保存总结、隐藏楼层可以在 **设置中心 → 撤回与事务** 里撤回；整理事实在“剧情事实”页撤回。
- 剧情剪辑台会尽量提供确认、草稿和撤回，但它不是版本控制系统。聊天正文、角色卡和世界书仍请自己备份。

## 常见问题

### 顶部显示“无可注入”，是配置丢了吗？

不是。这表示注入已开启，但目前还没有可用的长期记忆。可以先检查总结、待确认和注入内容页。

### 改了设置却没有效果？

设置页需要点顶部的 **保存设置**。保存栏显示“已核验保存”才表示保存成功。

### “查看上一轮”为什么是空的，或者不是最新设置？

它显示的是酒馆保存的上一轮实际发送内容，不会为了刷新而额外生成。新聊天还没回复过，或刚改了设置、还没进行下一轮对话时，会显示旧内容。

### 搜索提示词会把内容发给 API 吗？

不会。搜索完全在浏览器本地完成。

### 模型列表拉不出来？

先确认接口地址、密钥是否正确。有些服务不提供模型列表，可以直接手动填写模型名。做向量记忆时，还要确认服务确实支持 Embedding。

### 为什么阶段总结会停下来提示“记忆缺口”？

要整理的范围里有楼层缺少摘要。建议先到 **总结 → 剧情摘要**（下面的补写旧聊天表单） 补上缺口，再生成阶段总结。

### 本地轻量检索是真正的语义检索吗？

不是。它对人名、地点、术语这类明确的词效果好。需要更抽象的语义匹配时，请配置外部 Embedding。

### 删除或重新生成了旧楼层怎么办？

插件会检查受影响的总结、隐藏记录和向量索引，并尽量标记或回退。涉及重要剧情时，建议先备份再操作。

### 手机上偶尔很卡？

长聊天、批量生成、向量索引和大量展开的内容会叠加内存压力。可以缩小批次、收起不需要的面板、清理卡住的任务，并避免多个后台功能同时运行。

## 反馈问题

遇到问题时，最好附上：

- 酒馆版本与运行环境（电脑 / Termux / 其他）
- 剧情剪辑台版本
- 当前的摘要方式
- 出问题的页面和操作步骤
- 聊天大约有多少楼
- 截图或控制台错误（请先遮住 API Key 和私人内容）
